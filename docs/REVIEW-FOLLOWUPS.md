Independent reviews of EQUIPA changes end with findings rated CRITICAL to
INFO. The blocking ones are fixed before merge. The LOW ones are easy to
lose, so this file records each of them: whether it was **FIXED** (by which
task, and which test fails without the fix) or **LEFT** (and why).
